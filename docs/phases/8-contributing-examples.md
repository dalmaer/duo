# Contributing examples

The contract (phase 1) makes an example one file. This phase makes that
obvious to someone arriving cold: a guide in `docs/adding-an-example.md`, an
issue template that asks for the idea *per pose*, a skill in
`.claude/skills/duo-explorer/` so an agent can do it end to end, and a credit
line for whoever had the idea.

**Done when.** Someone who has not seen the repo adds an example from an issue,
using only the guide, and it passes review without a structural change.
